# 🎮 Unity Game Project

Proyek pengembangan video game yang dibangun menggunakan **Unity Engine** dan bahasa pemrograman **C#**.

---

## 🛠️ Teknologi & Tools
- **Game Engine:** Unity
- **Programming Language:** C#
- **Physics & Controller:** Rigidbody / CharacterController
- **Version Control:** Git & GitHub

---

## ✨ Fitur Utama
- [x] Kontrol pergerakan karakter responsif
- [x] Sistem interaksi dan deteksi petunjuk (Clue System)
- [x] Antarmuka pengguna (UI Quiz & Main Menu)
- [x] Manajemen siklus game (GameManager)

---

## 🎮 Kontrol Permainan (Default)
| Aksi | Tombol Keyboard |
| :--- | :--- |
| Bergerak | `W`, `A`, `S`, `D` / Panah |
| Aksi / Lompat | `Spasi` |
| Interaksi | `E` |
